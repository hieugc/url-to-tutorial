# UTV-001 · CLI, spotlight và video H.264

**Cam kết của backlog.** Fixture URL → plan → video H.264, ảnh các bước, báo lỗi selector.

**Trạng thái do repo ghi tại thời điểm đóng gói.** CLI + Driver.js + H.264 verified in Linux/macOS CI candidate; user MacBook M3 visual/CPU/RAM acceptance still required. Merlin cập nhật bằng chứng theo bản code thực chạy.

## Kiến trúc và phạm vi thi công

Điểm vào là dispatcher trong src/cli.mjs. CLI sở hữu parsing và đường dẫn, plan.mjs sở hữu Zod schema, render.mjs sở hữu vòng đời Chromium, video và report. Overlay thao tác trong document đang quay. Tái dùng các ES module này cho cả CLI và Studio. Việc còn lại chính là nghiệm thu video và tài nguyên M3. Nếu ffmpeg dừng giữa chừng, sửa nhánh encode để lần chạy sau có thể phục hồi mà vẫn bảo vệ video đã bàn giao.

| Plan.parse → validatePlanForExecution | JSON từ đĩa hoặc Studio, trước tạo browser | áp mặc định schema v1, kiểm id, cạnh, reachability rồi gom các bước click/fill/navigate thiếu duyệt | Plan chuẩn hóa và danh sách lỗi review |
| launch → ready → uniqueTarget | headed, Page, Target mỗi bước có đích | tạo context theo viewport; đợi DOM và font tối đa 3s ở bước chờ font; resolve frame nếu có, đợi hiển thị và đếm đúng 1 | Browser / Locator hoặc lỗi kèm selector |

## Model và ràng buộc dữ liệu

| Model / thuộc tính | Kiểu, ràng buộc và nơi dùng |

## Giao diện và quy cách trình bày

Overlay dùng Driver.js 1.10.2 từ package local. Popover trắng, chữ #10243a, Arial, rộng tối đa 360px, padding 24px, bo 16px. Title 22px/1.3, description 17px/1.6. Cursor tròn 20px #16a085 viền trắng 3px. Kiểm đầu và cuối cảnh ở 1280×720, gồm text tiếng Việt có dấu.

## Ca triển khai mẫu

Ví dụ tuyến demo: nạp examples/demo.plan.json → thay URL bằng fixture đang listen → validate → showStep → PNG → action → expected → bước tiếp. Với phần encode đề xuất: dùng tên tạm riêng cho lượt chạy, probe file tạm rồi publish độc quyền (ví dụ link file tạm sang tên cuối cùng trong cùng filesystem, xử lý EEXIST). Hai lượt chọn cùng outDir phải phát hiện xung đột trước khi cùng ghi report/raw; dùng khóa thư mục hoặc dành riêng thư mục con theo lượt.

## Mã giả thi công · Công bố MP4 sau khi xác minh

Các tên thao tác mô tả bên dưới có thể triển khai ngay trong hàm sở hữu luồng.

```text
reserveWritableRun(outDir)                  // độc quyền cho lượt này
try:
    captureRawAndCloseContext()
    encode(rawPath, temporaryMp4, signal)
    probe = inspectStreams(temporaryMp4)
    require h264, positiveDuration, size == plan.viewport
    publishExclusive(temporaryMp4, finalMp4)
    markReportCompleted()
finally:
    removeOnlyThisRunTemporaryFiles()
    releaseRunReservation()
```
