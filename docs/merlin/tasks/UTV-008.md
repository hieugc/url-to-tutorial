# UTV-008 · Phiên đăng nhập, che dữ liệu và iframe

**Cam kết của backlog.** Che dữ liệu trước capture, session riêng, adapter iframe rõ ràng.

**Trạng thái do repo ghi tại thời điểm đóng gói.** Memory-only manual login CLI + cross-origin iframe locator/spotlight + all-frame OTP detection + privacy E2E added; follow-up CI candidate pending; authenticated-site/M3 review pending. Merlin cập nhật bằng chứng theo bản code thực chạy.

## Kiến trúc và phạm vi thi công

Tách ngữ cảnh login và ngữ cảnh quay trong render.mjs; loginPrompt chỉ do CLI interactive truyền vào. Playwright quản lý storageState trong RAM. privacy.mjs chạy trong document, plan.mjs resolve locator qua frameLocator, overlay.mjs vẽ khung iframe dựa trên tọa độ viewport. Công việc cần làm rõ là mức kiểm chứng init script và cách xử lý artifact đã quay khi phát hiện challenge giữa chừng.

## Model và ràng buộc dữ liệu

| Model / thuộc tính | Kiểu, ràng buộc và nơi dùng |
|---|---|
| FrameTarget | {frame:{css:string},target:{css:string} hoặc {role,name}}. Dùng cho target, expected, condition.target. Role nằm trong enum ở Plan v1. |
| Privacy config | plan.redactSelectors?:string[]; marker data-tutorial-redacted trên node, window.__tutorialPrivacyError khi scan lỗi. Đề xuất thêm window.__tutorialPrivacyReady:boolean khởi tạo false ở mỗi document, chỉ true sau cài style và scan thành công. |
| Session | storageState object nội bộ Playwright, lifetime một lượt render. report.workflow.manualLogin:boolean; report chỉ có metadata bước. Không ghi token, mật khẩu, cookie hay giá trị fill. |

## Giao diện và quy cách trình bày

Login sử dụng Chromium headed và terminal prompt. Top-frame spotlight dùng Driver.js; iframe dùng DOM overlay #tutorial-frame-overlay, outline 3px #16a085, popover nền trắng, chữ #10243a, heading Arial 18px, body 14px. Kiểm dài dòng ở giới hạn cao 140px; nếu crop thì chỉnh placement/height theo viewport và xác minh lại ở 720p.

## Mã giả thi công · Quyết định trước khi cho phép lưu ảnh

Các tên thao tác mô tả bên dưới có thể triển khai ngay trong hàm sở hữu luồng.

```text
for frame in page.frames():
    state = readPrivacyReadinessAndChallenge(frame)
    if detached(frame): continue
    if not state.ready or state.error or state.challenge:
        throw capturePrivacyFailure()
beforeScreenshot(): assertSafeCapture(page)
onPrivacyFailure():
    stopRecordingAndFlushContext()
    quarantineOrRemoveThisJobCaptureOutputs()
    persistSanitizedFailure()
    suppressDownloadLinks()
```
