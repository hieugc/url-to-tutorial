**Cam kết của backlog.** JSON grounded trong observed DOM; phát hiện task không đủ dữ liệu.

**Trạng thái do repo ghi tại thời điểm đóng gói.** Offline + mocked AI CI PASS; live billable OpenAI run still requires user-supplied API key and relevance/privacy review. Merlin cập nhật bằng chứng theo bản code thực chạy.

## Kiến trúc và phạm vi thi công

Planner là bước chọn và dựng bản nháp sau discovery một trang, trước editor. Offline là mặc định. Hosted chỉ chọn ID; selector và bước thực thi lấy từ evidence trên server. Việc còn lại là kiểm tra relevance/riêng tư khi chạy thật và đóng khoảng trống ở dữ liệu goal gửi ra ngoài.

## Hợp đồng hàm và thứ tự gọi

| Điểm gọi / hàm | Input và điều kiện gọi | Process cần giữ hoặc thi công | Output / lỗi |
|---|---|---|---|
| candidatesFromDiscovery → unsafeCandidateLabel | discovery.report.pages từ UTV-010 | chọn trang hợp lệ đầu, lấy tối đa 20 ứng viên đầu vào; clean nhãn/CSS, loại trùng CSS, nhãn chứa private value hoặc chỉ thị không tin cậy, cấp candidate-N theo index nguồn | {url,title,candidates:[{id,text,css}]} hoặc insufficient evidence |
| selectOffline(goal,candidates) | ai=false | normalize tiếng Việt, tokenize, bỏ stopword, chấm số từ mục tiêu xuất hiện trong nhãn, giữ tối đa 6 có điểm dương | {selectedIds,reason}; không có match thì báo thiếu bằng chứng |
| selectWithOpenAI(goal,candidates,options) | ai=true trên local, có key server, không dùng cloud worker | kiểm goal và label trước fetch (bổ sung guard goal); Responses POST store:false, json_schema strict, input chỉ gồm goal và id/label; kết hợp signal hủy và timeout 30s kể cả khi có signal ngoài | response completed, parse JSON, kiểm ID và relevance, trả {selectedIds,reason,model} hoặc lỗi đã lược dữ liệu |
| verifySelection → verifyGoalRelevance | sau mọi provider, kể cả stub trả thẳng selection | 1–6 ID unique thuộc tập evidence; từng nhãn có lexical support theo goal; giữ thứ tự provider | Candidate[] đã xác thực hoặc lỗi cụ thể |
| goalPlanFromSelection → createGoalGuide | goal dài 4–400, language vi/en, outDir?, signal? | dựng highlight 3500ms từ css thật, thêm goal-stop 2000ms; save plan khi thành công; ghi goal-evidence.json trong finally | {plan,evidence,report}, caller CLI hoặc Studio tiếp tục validate |

## Model và ràng buộc dữ liệu

| Model / thuộc tính | Kiểu, ràng buộc và nơi dùng |
|---|---|
| Selection | selectedIds:string[], reason:string; model?:string ở hosted. Schema JSON chỉ có selectedIds/reason; giới hạn số lượng và membership kiểm lại ở server. |
| GoalEvidence | url,observedAt,candidates:[{id,text,css}],selectedIds,reason. Payload gửi hosted có {id,label}, không kèm css, HTML hay screenshot. |
| GoalReport | status,startedAt,finishedAt,url,goal,provider:openai hoặc offline-keyword,selectedIds,warnings[],error?. Với goal nhạy cảm, đề xuất từ chối trước khi lưu/đưa vào report. |

## Giao diện và quy cách trình bày

#goal-text có maxlength 400, checkbox #goal-ai mặc định tắt, #goal-generate dùng .btn.primary teal. Dưới 850px nhóm .goal-shortcut chuyển một cột. Dùng Inter/system; khi thiếu bằng chứng hiển thị nguyên nhân ở job output, giữ nội dung nhập để sửa. Nêu rõ những trường sẽ gửi ở cạnh checkbox hosted.

## Ca triển khai mẫu

Ví dụ goal “Giới thiệu Premium”, candidates candidate-1=Premium hosting, candidate-2=Liên hệ. Chọn candidate-1 → dùng đúng selector trong evidence → goal-1, goal-stop. Nếu provider trả candidate-2 hoặc ID chưa từng quan sát thì từ chối. Với goal chứa email giả lập, guard ở createGoalGuide và selectWithOpenAI từ chối trước lưu/gọi mạng; fake fetch phải có callCount=0.

## Mã giả thi công · Chặn dữ liệu riêng trước khi tạo report hoặc gọi hosted

Các tên thao tác mô tả bên dưới có thể triển khai ngay trong hàm sở hữu luồng.

```text
g = normalizeWhitespace(goal)
require 4 <= len(g) <= 400
if ai and unsafeCandidateLabel(g): failBeforePersistence()
source = candidatesFromDiscovery(await explore(url,{maxPages:1, language, signal}))
if ai:
    boundedSignal = anyOfOperatorAbortAndTimeout(signal, 30000)
    selection = await selectWithOpenAI(g,source.candidates,{signal:boundedSignal})
else: selection = selectOffline(g,source.candidates)
picked = verifyGoalRelevance(g,verifySelection(selection.selectedIds,source.candidates))
return buildAndPersistReadOnlyDraft(picked)
```
