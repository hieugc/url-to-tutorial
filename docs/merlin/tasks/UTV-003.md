# UTV-003 · Studio editor local và hợp đồng HTTP

**Cam kết của backlog.** Nhập URL, sửa/reorder steps, preview, download MP4.

**Trạng thái do repo ghi tại thời điểm đóng gói.** Studio local editor + cancel-job control + backend running cancellation added; Linux/macOS CI candidate pending; M3 visual QA pending. Merlin cập nhật bằng chứng theo bản code thực chạy.

## Kiến trúc và phạm vi thi công

UI hiện hành là HTML semantic + CSS thuần + ES module trong src/studio/. Backend là node:http, serve file tĩnh trên loopback. Dùng DOM API, HTML5 drag/drop và polling hiện có. Các route project/version/SSE trong ARCHITECTURE.md là định hướng. Công việc ở snapshot này là bảo toàn manifest khi edit, làm đúng vòng đời trạng thái và xác nhận trải nghiệm ở kích thước desktop/mobile.

## Model và ràng buộc dữ liệu

| Model / thuộc tính | Kiểu, ràng buộc và nơi dùng |
|---|---|
| EditorState | plan:Plan hoặc null, selected:number (index), discoveryJobId:string hoặc null, pages:number, ready:boolean, busy:boolean, activeJobId:string hoặc null. Source hiện chưa có draft revision; nếu validate bất đồng bộ thêm counter cục bộ tăng mỗi lần invalidate để bỏ reply cũ. |
| ValidationResult | valid,ready:boolean; errors:Array<{path,message}>; reviewIssues:string[]. Server dùng thêm plan nội bộ, bỏ trước khi trả JSON. |
| JobDetail | id,type,status,startedAt,finishedAt,error,cancelRequested,report; discovery?/goal?/hostinger? theo type; videoUrl?,subtitleUrls?:{srt,vtt}. Client chỉ dùng URL server cấp. |
| LocatorForm (đề xuất, chỉ trong UI) | kind css/role/none, css,role,name,frameCss; encode trả Target hoặc undefined. Dùng cùng bộ chuyển cho target, expected, condition.target. Target lồng chỉ 1 cấp. |

## Giao diện và quy cách trình bày

Giữ grid thứ tự danh sách → editor → Readiness. Ở ≤1170px Readiness xuống hàng; ≤820px một cột; ≤440px action hai cột. Dùng CSS variables trong CONTRACTS.md. Nút chính teal, nút phụ trắng; active row dùng mint. Inter/system, form kế thừa font; advanced JSON ui-monospace. Giữ skip-link, label/for, nút ↑↓ dùng bàn phím, aria-live cho output. Locator iframe bổ sung ô “Frame CSS” có nhãn rõ, dùng cùng .field. Khi action/URL/target/value đổi, buộc duyệt lại nội dung mới trước execution.

## Ca triển khai mẫu

Ca round-trip: import bước highlight có target={frame:{css:"#demo"},target:{role:"button",name:"Tiếp"}}; sửa riêng title; Save → Export. Target phải deepEqual trước/sau. Với expected kiểu role hoặc frame cũng tương tự. Ca race: Validate plan A, đổi title sang B trước khi A trả về; chỉ chấp nhận response có revision đang hiển thị. Với job được khôi phục sau restart, interrupted phải giải phóng busy ngay khi poll thấy trạng thái đó.

## Mã giả thi công · Lưu locator lồng mà vẫn dùng form hiện hữu

Các tên thao tác mô tả bên dưới có thể triển khai ngay trong hàm sở hữu luồng.

```text
readTarget(group):
    inner = readCssOrRolePair(group)
    if inner is empty: return undefined
    if group.frameCss.trim(): return {frame:{css:group.frameCss.trim()}, target:inner}
    return inner

commitStep():
    next = clone(old)
    patchEditedFields(next, form)
    for group in [target, expected, condition.target] applicable to next.action:
        writeOptionalTarget(next, group, readTarget(form[group]))
    clearFieldsInvalidForAction(next)
    if executionFieldsChanged(old, next): next.reviewed = false
    if changed(old,next): replaceStep(next); invalidate(); refresh()
```
